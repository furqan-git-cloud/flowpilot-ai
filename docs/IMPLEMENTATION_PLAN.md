# FlowPilot AI Implementation Plan

## Included in this MVP

- Responsive Next.js dashboard
- English, Urdu and Arabic language switching
- RTL layout support
- Workspace, project, task and workflow API
- Template-based workflow generation and allowlisted execution
- Analytics overview
- Pytest API smoke tests

## Production milestones

- Supabase Auth and JWT verification
- PostgreSQL migration from local SQLite
- Workspace membership and role authorization
- Row Level Security
- CRM and inventory
- Reminders and audit events
- Deployment and monitoring
